# 📂 HTML Assignment Viewer using Iframe

A simple HTML and CSS project that uses an **iframe** to display multiple HTML assignments on a single webpage. The left sidebar contains navigation buttons, and clicking any button loads the selected assignment inside the iframe.

## 📌 Features

- Sidebar Navigation Menu
- Display Multiple Assignments in One Page
- Iframe Integration
- Clean and User-Friendly Interface
- Easy Navigation Between Assignments
- Responsive Flexbox Layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- Iframe
- Flexbox

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `iframe.html` in any web browser.
4. Click any assignment button to load the corresponding page inside the iframe.

## 📚 Concepts Used

- HTML Iframe
- Hyperlinks (`<a>`)
- `target` Attribute
- CSS Flexbox
- Sidebar Navigation
- Page Layout

## 📸 Output

The webpage displays:

- A navigation sidebar with assignment buttons.
- An iframe on the right side.
- Clicking any assignment button loads that page inside the iframe without opening a new browser tab.
